# House Price Prediction - MLOps Project

## Project Overview

This project implements an end-to-end MLOps pipeline for predicting house prices using real estate data.

The dataset contains property information such as location, property type, area, bedrooms, bathrooms, and price details. The project covers the complete machine learning lifecycle including data processing, model training, experiment tracking, version control, API development, containerization, and deployment.
The objective is to build a machine learning system that predicts property prices based on real estate features.

Input:
- Location
- City
- Property Type
- Bedrooms
- Bathrooms
- Area Size etc

Output:
- Predicted Property Price
